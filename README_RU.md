# STREAMX STUDIO — версия 0.1.0

Настольное приложение для Windows на Electron с тёмным фиолетовым интерфейсом.

## Запуск
Установи Node.js LTS, открой PowerShell в папке проекта и выполни:
```powershell
npm install
npm start
```

## Сборка установщика
```powershell
npm run dist
```
Готовый установщик появится в папке `dist`.

## Важно
Интеграции Twitch, YouTube, Discord и AI требуют отдельных API-ключей и настройки. Не публикуй секреты в репозитории.
